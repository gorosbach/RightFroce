metadata embedded in the supplied PSID files.

- **Track:** Task Force
- **Authors:** Rob Hubbard & Jason Page
- **Release metadata:** 2018 Project Hubbard
- **Files:** `assets/music/Task_Force.sid` and the derived runtime payload
  `assets/runtime/title-music.bin`

## In-game music

- **Track:** Lightforce 2006
- **Author:** Glenn Rune Gallefoss
